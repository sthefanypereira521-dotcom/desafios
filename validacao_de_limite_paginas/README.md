# Simulador de Leitura

Um script simples pra simular a leitura de um livro, página por página, direto no terminal. Fiz esse projeto pra praticar orientação a objetos em Python (classes, atributos, métodos) e de quebra usar a biblioteca rich pra deixar o terminal mais bonito no console.

## O que ele faz

- Cria um livro com título, autor, total de páginas e sumário
- Avança as páginas aos poucos, simulando a leitura em tempo real
- Avisa quando o livro chega ao fim
- No final, mostra o sumário completo com os capítulos

## Tecnologias

- Python
- rich pra colorir e formatar o texto no terminal

## Como rodar

pip install rich
python validacao_paginas.py

## O que eu pratiquei aqui

- Criação de classes e objetos
- Métodos que alteram o estado do objeto (`avancar_paginas`)
- Uso de `sleep` pra simular passagem de tempo
- Formatação de texto com `rich`
